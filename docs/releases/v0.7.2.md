evidencestore is an independent witness for logs. A collector next to the log sends every line to a store on another machine, and the store can later prove any of those lines to an auditor, offline and without being trusted: the exact bytes, their place in a hash chain, a signed chain head and RFC 3161 time-stamps from before and after the record. Retention works by destroying a month's key: the bodies become unreadable in every copy, while the chain and the proofs stay valid.

This release adds a try in one command and makes the README short. The store, the collector and `esverify` are those of v0.7.1.

## New in this release

- **A try in one command, with nothing but Docker.**

  ```sh
  docker run --rm ghcr.io/nikolay1994kaz/evidencestore
  ```

  Inside the container a collector sends three lines of a practice `auth.log` to a store, an intruder deletes the line with their address from the file, and the store gives it back as a proof bundle: `esverify` prints `VERIFIED` with the deleted line as its body, and `NOT VERIFIED` for the same bundle with one byte changed. It takes about a second; nothing leaves the container.
- **A short README**, with the details on their own pages: [Quick start](https://github.com/Nikolay1994Kaz/evidencestore/blob/v0.7.2/docs/quick-start.md) (the try, the store on a log of your own, the demos), [How it works](https://github.com/Nikolay1994Kaz/evidencestore/blob/v0.7.2/docs/how-it-works.md) (the steps and the components) and [Development](https://github.com/Nikolay1994Kaz/evidencestore/blob/v0.7.2/docs/development.md).

## Upgrading

Nothing changes. A store in Docker can stay on v0.7.1, or take the `compose.yaml` of v0.7.2 for its image.

## Install

In Docker, on the store's host:

```sh
curl -fsSLO https://raw.githubusercontent.com/Nikolay1994Kaz/evidencestore/v0.7.2/deploy/docker/store/compose.yaml
ES_HOST=logs.example.com docker compose up -d
docker compose exec -T store add-collector web1 > web1.tgz
```

and on web1: `tar -xzf web1.tgz && cd web1 && docker compose up -d` ([In Docker](https://github.com/Nikolay1994Kaz/evidencestore/blob/v0.7.2/docs/install.md#in-docker)). Check the image: `gh attestation verify oci://ghcr.io/nikolay1994kaz/evidencestore:v0.7.2 --repo Nikolay1994Kaz/evidencestore`. Binaries with `SHA256SUMS` and attestations are on this page; with Go: `go install github.com/Nikolay1994Kaz/evidencestore/cmd/...@v0.7.2`.

## How it was tested

The test gate with the race detector, and `scripts/docker-check.sh` on every push and on the published image of this release: it now also runs the try and requires the deleted line back and the forgery caught.

## Before you use it

- Until 1.0 the on-disk formats (evidence log, chain, keyring) may change; each release will describe the way over.
- The pilot cryptography is not certified: AES-256-GCM from the Go standard library, root keys in files. The root store is a plug-in point for an HSM.
- Read [Known limitations](https://github.com/Nikolay1994Kaz/evidencestore#known-limitations).
